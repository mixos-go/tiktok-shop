# TikTok Shop OpenAPI Guide

Use this skill to answer exact TikTok Shop OpenAPI structure questions and avoid
selecting a stale endpoint version.

## Coverage

- Platform: TikTok Shop OpenAPI (base `https://open-api.tiktokglobalshop.com`).
- 25 category folders under `references/api/` (product, order, fulfillment,
  return_refund, logistics, promotion, finance, seller, authorization, event, affiliate,
  customer_service, data_reconciliation, review_rating, supply_chain, analytics,
  epharmacy, fbt, gs_full_service_*, etc.), 363 API docs total.
- Each doc has YAML frontmatter (`title`, `category`, `api_name`, `method`, `path`) plus
  structured sections: `## API Description`, `## Request Parameters`, `## Request Body`,
  and `## Response`.
- Endpoint paths embed the six-digit API version (e.g. `/product/202309/products/search`).
  Prefer the highest official version unless pinned.
- Auth: `app_key` + `app_secret`, request signing parameter, and access token per region.

## Workflow

1. Define the requested business capability. Record any explicit method/path, version
   pin, and any region / authorization / rollout / lifecycle / workflow constraint.
2. Map the capability to a category (e.g. product → `product`, order → `order`,
   return → `return_refund`, logistics → `logistics`, fulfillment → `fulfillment`).
3. Inspect `references/api/<Category>/<operationName>.md`; collect every operation that
   implements the requested capability, including method, path, six-digit version, and schema.
4. Treat bundled reference as a local baseline, not proof its newest entry is current.
   Before finalizing method and path, check official Partner Center docv2
   (`https://partner.tiktokshop.com/docv2/page/{api}-{version}`) for newer candidate
   versions absent from the snapshot.
5. Unless the user or a registered workflow pins a version, choose the highest six-digit
   version among applicable official candidates. Do not replace the requested capability
   with a semantically adjacent operation solely because it is newer.
6. If a newer official operation is missing from bundled reference, use its official
   docv2 schema and report the OAS coverage gap.
7. Do not infer fields, enum values, required flags, or response shapes absent from the
   selected operation's official schema.

## References

- `references/api/<Category>/<operationName>.md` — one clean Markdown doc per TikTok Shop
  operation, grouped by first-level API path (category).
- Endpoint `path` in frontmatter includes the six-digit version segment.

## Update & Provenance

- Local reference is a **static snapshot** generated from the official TikTok Shop OpenAPI
  spec bundled in the `@tts-open-toolkit/cli` npm package. It is regenerated by the
  toolchain in the `updskills` repo (`tools/oas_to_markdown.py`). To get fresher APIs,
  update `@tts-open-toolkit/cli` and re-run the tool rather than hand-editing.
- For agent use, prefer the official live docs (`https://partner.tiktokshop.com/docv2/`)
  for anything that may have changed since this snapshot (deprecations, new versions,
  policy).
