**Category:** return_refund
**API:** RejectCancellation

**Method:** POST
**HTTP Path:** https://open-api.tiktokglobalshop.com/return_refund/202309/cancellations/{cancel_id}/reject

## API Description
Use this API to reject a buyer's order cancellation request.

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| cancel_id (path) | string | Yes | The identifier of a specific cancellation request. |
| idempotency_key (query) | string | No | The idempotency key is a unique value generated by the client which the server uses to recognize a request. You may choose your own method of creating unique keys. We suggest using UUIDs, or another random string with enough entropy, to avoid collisions. Idempotency keys can be up to 255 characters |
| shop_cipher (query) | string | No | Use this property to pass shop information in requesting the API. Failure in passing the correct value when requesting the API for cross-border shops will return incorrect response. |
| x-tts-access-token (header) | string | Yes |  |
| Content-Type (header) | string | Yes | Allowed type: application/json |

## Request Body
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| comment | string | No | Seller's comment on rejection decision. This is where a seller will provide more information about rejecting the request. (e.g. I have packed the products before cancellation request) |
| images | array<object> | No | List of images provided by the seller to support seller's decision to reject the order cancellation request. |
| reject_reason | string | No | Seller's reason to reject buyer's order cancellation request. Please visit our [cancel reason appendix ](650b28280fcef602bf435096) to see a list of possible rejection reasons. (e.g. seller_reject_apply_product_has_been_packed) |

## Response
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| code | integer | No | The success or failure status code returned in API response. |
| data | object | No | Specific return information. |
| message | string | No | The success or failure messages returned in API response. Reasons of failure will be described in the message. |
| request_id | string | No | Request log. |
