**Category:** review_rating
**API:** ImportProductReviews

**Method:** POST
**HTTP Path:** https://open-api.tiktokglobalshop.com/review_rating/202508/product_reviews

## API Description
Import product reviews from external sources to TikTok Shop. Sellers with popular products on other platforms can overcome the cold start on TikTok Shop by showcasing verified external reviews to build greater trust in the products and help customers make informed purchasing decisions. **Note** - Imported reviews cannot be edited, updated, nor deleted, therefore please exercise caution during import. To make any changes, you need to submit a request through the Seller Center, and all requests are subject to TikTok Shop's approval. - Use the [Upload Review Media API] to upload review images or videos first and obtain the URIs before calling this API.

## Request Body
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| product_review | object | No | Product review information based on existing reviews from an external source. |
| product_review.product | object | No | The product being reviewed. |
| product_review.product.description | string | No | The description of the product. Max Length: 750 characters (e.g. While the look is visually appealing, you'll appreciate the durability of this t-shirt and will be utterly pleased with how smooth the fabric is. ) |
| product_review.product.identifiers | object | No | Recommendations - We suggest that you use TikTok Shop product IDs, if available, for precise matching. - The system will attempt to match the non-TikTok Shop identifiers (e.g. Shopify product ID, GTIN, UPC, EAN, ISBN), but there may be no match if these values were not included during the creation of the TikTok Shop product. Please add or edit the external identifiers in the relevant product to align with the ones used in the reviews. Note: This identifier must be associated with only one TikTok Shop product. The API request will fail if multiple products share the same identifier. Please update the relevant products and try again. |
| product_review.product.identifiers.external_product_id | string | No | An external product or SKU identifier used in an external ecommerce platform. An external identifier used in an external ecommerce platform. This is used to associate the product between TikTok Shop and the external ecommerce platform. (e.g. 789456123012) |
| product_review.product.identifiers.product_identifier_code | string | No | An internationally regulated identifier code, including GTIN, EAN, UPC, or ISBN. (e.g. 12389456123012) |
| product_review.product.identifiers.seller_sku | string | No | A unique identifier that sellers use to track and manage their inventory. Seller SKU is defined by the seller. An internal code/name for managing SKUs, not visible to buyers. (e.g. ABC-XYZ) |
| product_review.product.identifiers.tiktok_product_id | string | No | A product ID generated by TikTok Shop. This is equivalent to the products.id returned in the Search Products API. Intended for use by connector app developers. (e.g. 123456) |
| product_review.product.image_uris | array<string> | No | The URI of main product images associated with the product. Retrieve the URI from the [Upload Review Media API]. Max count: 1 |
| product_review.product.name | string | No | The product name. Max length: 255 characters (e.g. Organic Cotton T-Shirt) |
| product_review.review_records | array<object> | No | The list of reviews to import for the product. Max count: 50 |
