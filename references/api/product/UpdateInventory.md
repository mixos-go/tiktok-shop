**Category:** product
**API:** UpdateInventory

**Method:** POST
**HTTP Path:** https://open-api.tiktokglobalshop.com/product/202309/products/{product_id}/inventory/update

## API Description
Update the inventory quantity of SKUs belonging to a product. The SKU ID must belong to a product that is **not** in `FREEZE` or `DELETED` status.

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| product_id (path) | string | Yes | The product ID generated by TikTok Shop. |
| shop_cipher (query) | string | No | Use this property to pass shop information in requesting the API. Failure in passing the correct value when requesting the API for cross-border shops will return incorrect response. |
| x-tts-access-token (header) | string | Yes |  |
| Content-Type (header) | string | Yes | Allowed type: application/json |

## Request Body
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| skus | array<object> | No | A list of Stock Keeping Units (SKUs) used to identify distinct variants of the product. |

## Response
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| code | integer | No | The success or failure status code returned in API response. |
| data | object | No | Specific return information. |
| data.errors | array<object> | No | The list of errors that occurred. |
| data.errors.detail.extra_errors | array<object> | No | A list of secondary errors or issues related to the main error. |
| data.errors.detail.sku_id | string | No | The ID of the SKU where the error occurred. (e.g. 1729592969712207013) |
| message | string | No | The success or failure messages returned in API response. Reasons of failure will be described in the message. |
| request_id | string | No | Request log. |
